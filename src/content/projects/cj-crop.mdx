## Project overview

The **Design Your Future** competition by CJ Corporation challenged participants to create innovative product solutions. My approach went beyond conceptual design, focusing on a robust **UX/UI System Design** that bridges the gap between Figma mockups and production-ready code.

## Design thinking & System design

A core focus of this project was establishing a comprehensive design system that serves as a single source of truth for both designers and developers.

### Context and Layout (Bối cảnh & Bố cục)

The user interface was designed with a deep understanding of the user's context. I mapped out various user journeys to ensure the layout is intuitive, minimizing friction when navigating through complex data and actions. The layout principles emphasize whitespace, visual hierarchy, and accessibility.

### Color Palette (Bảng màu)

I developed a semantic color palette that communicates meaning intuitively:
- **Primary colors**: Used for main actions and branding.
- **Feedback colors**: Success, warning, and error states designed with high contrast.
- **Neutral scale**: Carefully selected grays for typography and borders to reduce eye strain.

### Component-driven architecture (Coded Widgets)

Instead of stopping at Figma, the design was translated directly into **reusable coded components/widgets**. These components act as a living system design:

- Buttons, inputs, and cards were built with strict adherence to the design tokens.
- Interactive widgets were prototyped in code to test the actual feel of micro-interactions and animations.
- This approach ensured that what was designed could be seamlessly integrated without visual discrepancies.

## The Outcome

The project was recognized in the **Top 5 Excellent Projects** out of numerous submissions. By combining solid design thinking with technical execution, I demonstrated how a well-structured system design can elevate a product from a mere concept to a practical, working solution.
